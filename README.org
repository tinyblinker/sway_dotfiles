#+TITLE: Sway Dotfiles
#+AUTHOR: shyweeds

* About

My Arch Linux + Sway desktop config. GNU Stow manages the symlinks.
There are two machines: HP laptop and mini PC.
The =sway= and =alacritty= symlinks choose the machine.
Rime config is a Stow package in =rime/=.
Every deploy step runs through =deploy.sh=.

* Usage

** Install software

#+begin_src sh
./deploy.sh software
#+end_src

Update the system, install or remove packages, and turn on services.
Mihomo comes from =./pkgs/mihomo-*.pkg.tar.zst=.
Set =MIHOMO_PKG_DIR= to use another folder.

** Install Rime

#+begin_src sh
./deploy.sh after_mihomo
#+end_src

Install rime-ice with Xiaohe double pinyin (Flypy), update the grammar and
reverse-tone models, and link the patch in =rime/=. The patch adds
=in <-> ing= fuzzy pinyin.

** Switch machine

#+begin_src sh
./deploy.sh switch mini_pc   # or hp_laptop
#+end_src

** Deploy configs

#+begin_src sh
./deploy.sh config
#+end_src

Link user and system configs with Stow, and turn on systemd user services.
This also links the Rime patch and reloads fcitx5.
=./deploy.sh= does the same as =./deploy.sh config=.

** Mihomo config

#+begin_src sh
./deploy.sh decrypt   # config.enc.yaml -> etc/mihomo/config.yaml
./deploy.sh encrypt   # etc/mihomo/config.yaml -> config.enc.yaml
#+end_src

Needs =sops= and =age=.
