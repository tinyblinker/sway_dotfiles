#+TITLE: config.yaml
#+OPTIONS: toc:nil

* What it is

A single-file =mihomo= config, converted from Clash Verge Rev.

Sensitive values (the subscription =url= and the DNS =nameserver-policy= URLs)
are encrypted with sops + age.

* Sections

| Section          | Purpose                                            |
|------------------+----------------------------------------------------|
| General          | Listen ports, mode, log level, ipv6                |
| External control | API, dashboard (=metacubexd=), CORS                |
| Profile          | Store group selection and fake-ip mapping          |
| Sniffer          | Sniff TLS / HTTP / QUIC for domain-based routing   |
| TUN              | Transparent proxy (needs root)                     |
| DNS              | Fake-ip, resolvers, per-domain policy, fallback    |
| Proxy providers  | Subscription (the node source)                     |
| Proxy groups     | Select + auto + fallback + ChatGPT + 7 regions     |
| Rule providers   | =geosite=: =cn_domain=, =geolocation-!cn=          |
| Rules            | 241 inline rules + 2 =RULE-SET=                    |

* Notes

- =tun.enable: true= needs root.
- =rule-providers= and the dashboard download on first start (need network).
